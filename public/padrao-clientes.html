Análise de Padrão de Clientes

Ferramenta manual. Você cola um lote de conversas, o sistema extrai só o padrão agregado (números) e apaga o texto na hora — nenhuma conversa fica salva em lugar nenhum.

Como colar

Separe cada conversa com uma linha só com -----.
No início de cada conversa, coloque uma linha RESULTADO: comprou, RESULTADO: quase ou RESULTADO: não avançou — é você quem sabe o resultado real, o sistema só lê os sinais do texto.
Sinais que o sistema procura: se o cliente disse que foi/está na loja, se perguntou sobre entrada nas primeiras linhas, e se a conversa foi longa (15+ mensagens).
