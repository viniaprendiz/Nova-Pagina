Como adicionar um projeto novo: abra este arquivo (public/projetos.html) e edite a lista PROJETOS lá no início do script. Copie um bloco, troque nome, tipo, status (rascunho / andamento / concluido / no-ar), progresso (0 a 100) e a observação. Se o projeto já estiver no ar, pode incluir um link.
