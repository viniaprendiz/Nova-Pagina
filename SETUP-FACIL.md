# 🚀 SETUP SUPER-FACIL - 3 PASSOS

## PASSO 1: Abrir Terminal
Aperta: `Windows + R` (ou clica lupa no windows)
Digita: `cmd`
Aperta: Enter

## PASSO 2: Clonar Repo
Cola isto no terminal (copy-paste):
```
git clone https://github.com/viniaprendiz/Nova-Pagina.git
cd Nova-Pagina
```

## PASSO 3: Executar Sistema
Cola isto (copy-paste):
```
npm install
npm run maestral
```

## PRONTO!
Sistema ativo. Agora avisa Claude que completou!
